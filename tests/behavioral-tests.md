# 行为测试记录

日期：2026-10-10。所有输入均为本项目自编的文献节选或边界测试材料，不对应真实发表的论文；数值仅属于测试文本，不应引用为研究证据。

方法：当前助手读取 Skill，将下列输入作为待概括材料，生成本文件中的输出，再逐句对照输入检查事实、限定条件、文章类型和卡片数量。没有调用独立评估模型；这些记录可用于后续重新运行和人工比较，不代表自动化测试或全文 PDF 解析测试。

## 1. 实证文章：证据不足和量级

输入：

```text
摘要节选：80名学生被随机分为阅读训练组和对照组，每组40人。四周后的词汇测验满分100分，训练组均值72分，对照组70分；组间差异检验p=0.12。作者认为现有结果未提供训练改善词汇分数的充分证据，并指出随访仅四周。
```

输出：

```markdown
### 知识卡片 1
**标题：** 阅读训练改善的证据不足
**摘要：** 基于所提供的摘要节选，四周后的词汇测验满分100分，训练组平均72分，对照组70分；组间差异检验p=0.12。作者认为现有结果未提供训练改善词汇分数的充分证据。

### 知识卡片 2
**标题：** 随机分组与四周随访的边界
**摘要：** 80名学生被随机分为两组，每组40人。作者指出随访仅四周；所提供的节选没有报告更长期的结果。
```

核对：组别、均值、满分单位、p值、人数和时间均可直接回溯；未将均值较高写成有效，未把证据不足写成无效。两张卡片分别处理发现与设计。最终版本通过；初次输出与修改见文末。

## 完善与复核

初稿审核发现默认“发现／方法”分法对综述和理论文章不够具体，并且没有明确非显著结果、数值冲突的处理。围绕上述用例补充文章类型分法、数值与限定条件的保留、冲突处理和文献内嵌指令的边界。

用例1初次输出的标题为“阅读训练的组间分数差异未达显著”。复核发现“未达显著”依赖未给出的显著性阈值。最终将卡片标题改为“阅读训练改善的证据不足”，摘要保持p=0.12与作者自己的结论；同时要求 Skill 不自行补写未给出的显著性阈值。其余输出不变。上文保存最终版本；改后标题仍直接来自原文，没有添加0.05等阈值。

最终结果：9个场景均满足各自的事实与行为检查；材料充足的7个场景输出两张卡片，材料不足或等待中的场景说明所需输入。本记录不把结构验证当作忠实性验证。
